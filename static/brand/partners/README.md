# Partner logos (auth footer)

Place four logos here, same filenames the footer expects:

- `partner-1.webp`
- `partner-2.webp`
- `partner-3.webp`
- `partner-4.webp`

PNG also works if you rename the `src` in `templates/account/components/auth_footer.html`
(or save as `.webp`). Keep them roughly the same visual height so they align.
